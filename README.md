## 这是什么？

这不是又一个"调包教程"。这里每一行公式都是手推的，每一段代码都是手写的，每一道面试题都是按"面试官能听懂"的标准准备的。

**目标岗位**：算法工程师（推荐系统 / 搜索 / NLP / Agent）

**覆盖内容**：
- 🤖 **机器学习基础** — 线性回归→树模型→聚类→PCA→神经网络→Transformer
- 🎯 **推荐系统** — 召回→排序→重排→冷启动→A/B测试
- 📊 **深度学习推荐** — Wide&Deep / DeepFM / DIN / DIEN / MMOE
- 💻 **手撕代码** — 70道力扣高频题 + 手写排序
- 🗣️ **面试话术** — 175道八股文标准答案
- 🏗️ **项目叙事** — 指标脱钩 / 场景分割 / 消融分析

## 面试回答模板（三段式）

每个答案都按这个结构组织：

```
第1段 — 直觉（一句话说清这个算法在干什么）
第2段 — 关键公式或逻辑（能写出来的数学）
第3段 — 关联项目（和你做过的项目怎么连）
```
